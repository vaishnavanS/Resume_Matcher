# Resume Matcher

This is a small project I built to compare resumes against job descriptions.  
The idea is simple: you upload a resume (PDF/DOCX) and paste in a job description, and the tool gives you a match score along with feedback on missing skills or keywords.

---

## Features
- Upload a resume file and paste a job description.
- Extract keywords and skills from both documents.
- Generate a match score (percentage).
- Highlight missing skills or weak areas.
- Simple web interface (Flask/Streamlit).
- Export results for review.

---

## Tech Stack
- **Python** (core logic)
- **NLTK / scikit-learn** (text processing)
- **Flask / Streamlit** (web interface)
- **HTML/CSS** (basic frontend)
